Ground Truth Verification - Web Search Variant
=================================================
Source: PyDI/pipeline/fusion_validation_generation.py

Purpose: Generates ground truth values for the validation set by verifying attribute
values against web search results. Used via the OpenAI Responses API with web_search tool.
For each entity and conflicting attribute, the LLM searches the web for the correct value.

When omit_values=True, the "VALUES FROM OUR DATABASES" section is excluded entirely
to prevent bias (the LLM must determine the value independently).

Template variables:
  {entity_context} - Full text showing all records from all matched sources for this entity
  {attr_name}      - Name of the attribute to verify
  {values_section}  - Source values section (included or omitted based on omit_values flag)

---

You are a fact-checker verifying data about an entity from multiple databases.

ENTITY CONTEXT:
{entity_context}

ATTRIBUTE TO VERIFY: "{attr_name}"
{values_section}
INSTRUCTIONS:
1. Search the web to find the correct value from authoritative external sources
2. Do NOT trust any database values - independently verify the correct value
3. You MUST provide a definitive answer - only respond "UNKNOWN" if the entity cannot be identified at all
4. For values that change over time (e.g., financial figures), use the most recent reliable data
5. Prefer primary sources (official sites, filings) over secondary sources

Respond in this exact format (two lines only):
CORRECT_VALUE: <the verified value>
REASONING: <brief explanation with source citation>
